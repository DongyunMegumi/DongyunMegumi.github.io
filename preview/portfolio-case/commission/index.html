01 / SERVICE

制作内容

根据角色立绘制作 VTuber 三维模型。

交付格式
VRM；FBX / Unitypackage 可另行沟通
参考交期
开工后约 2–3 个月 参考参数；VGen 原条款约 4–6 周，正式交期需统一确认。
参考表情
16 种，包含口型、眨眼及情绪表情
价格
根据角色设计与追加需求单独报价
02 / OPTIONS

追加项目

  • 额外表情
  • MMD 表情制作
  • Perfect Sync 支持
  • 部件显示 / 隐藏切换
  • Magica Cloth2 支持（交付 VRM 与 Unitypackage）
  • Warudo 设置（交付 VRM 与 Warudo 文件）
  • 制作过程直播许可（允许直播制作过程时可提供折扣）

以上为参考项目，能否提供及费用需另行确认。

03 / PROCESS

交付流程

  1. 开工前支付报价的一半

  2. 开始制作

  3. 每 1–2 周一次进度汇报，根据反馈修改

  4. 制作完成

  5. 交付模型，根据反馈修改

  6. 交付完成

  7. 支付报价剩余的一半

以上暂按参考流程展示。尾款与文件交付顺序与下方 VGen 条款不同，正式委托前需统一确认。

模型制作流程

  1. 粗模造型

  2. 细节造型

  3. 绑定 / 蒙皮（关联模型与骨骼）

  4. UV 展开

  5. 贴图绘制 / 上色

  6. 表情制作

  7. VRM 设置

04 / MATERIALS

准备资料

报价时提供的资料

  • Live2D 等角色立绘。
  • 三视图（没有也可以；有助于提高后发等细节的还原度）。
  • 考虑追加的项目。

报价后、确认委托时提供的资料

  • 分层 PSD 文件（没有请提前说明）。
  • Live2D 表情截图，或预想表情的参考资料。
  • 角色身高。
  • 角色名字的拉丁字母拼写。
  • 计划使用的 VRM 导入软件。
05 / TERMS OF SERVICE

VGen 服务条款

委托资格与付款

成年或由监护人订约；授权使用角色资料。首款 50% 后开工，尾款 50%；标价另加 10% VGen 费用，首款不退。

修改与交付

可在进度节点反馈，修改不等于重做或新增设计；额外需求另报价，可能延长交期。原条款参考工期约 4–6 周，受追加项目及排期影响。付清后交数字文件；交付后一周内可申请一次免费遗漏问题修复。

取消与退款

委托人取消，已付款不退；制作者取消，全额退款。取消模型按原条款处理。

授权、署名与作品公开

制作者保留著作权；客户获得专属、不可转让使用权，需署名。允许收益直播；销售、商品化、再分发或公开模型须另获授权并议价。默认可作作品展示；保密另收费，NDA 至客户公开或完工两个月结束。

沟通与条款待确认处

通过 Email / Discord / X 私信沟通，在造型、贴图及 VRM 设置节点反馈。原文同时出现“交付后不修改”和“一周内免费修复”，另有“仅个人使用”及“允许收益直播”等表述；正式约稿前需统一适用范围。
