# Web Fonts

Jost is used for the English navigation, dates and headings, matching the font family observed on https://hachi-official.jp/. Noto Sans JP is used for Japanese/CJK text, with Noto Sans SC as the simplified-Chinese fallback.

These files were downloaded through the official Google Fonts CSS API. Jost includes the Latin variable-font subset. The Noto files are Google-provided subsets covering the current preview UI and the two existing journal entries. New text outside those subsets uses the system fallback until the subsets are regenerated. No proprietary font or icon font was copied from the reference website.

Sources and licenses:

- https://github.com/google/fonts/tree/main/ofl/jost
- https://github.com/google/fonts/tree/main/ofl/notosansjp
- https://github.com/google/fonts/tree/main/ofl/notosanssc

All three families use the SIL Open Font License 1.1. Their original license files are included alongside the fonts. These assets are served locally, without third-party font requests at page load.
